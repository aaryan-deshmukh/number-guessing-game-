# Number Guessing Game

A full stack number guessing game — Java backend handles the game logic, HTML/CSS/JS frontend handles the interface. Runs locally on `localhost:8080`.

## How it works

The backend generates a random target number and manages guess validation, difficulty levels, and scoring. The frontend sends guesses to the backend and displays results, score, and game state in the browser.

## Tech stack

- **Backend:** Java (Maven project)
- **Frontend:** HTML, CSS, JavaScript
- **Other:** Leaderboard tracking (leaderboard.txt)

## Running locally

1. Clone the repo: git clone https://github.com/aaryan-deshmukh/number-guessing-game-.git
2. Navigate into the project: cd number-guessing-game-/Java_Game
3. Build and run with Maven (or your IDE's run configuration for GameServer.java).
4. Open http://localhost:8080 in your browser.
